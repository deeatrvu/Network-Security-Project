Secure Web-Based Voting System - Code Explanation
==============================================

Project Structure Overview
-------------------------
/
├── client/               # Frontend React application
│   ├── src/
│   │   ├── components/  # React components
│   │   ├── utils/       # Utility functions
│   │   └── App.js       # Main application component
└── server/              # Backend Node.js application
    ├── controllers/     # Request handlers
    ├── models/          # Database models
    ├── utils/          # Utility functions
    └── server.js       # Main server file

1. SERVER-SIDE COMPONENTS
========================

1.1 Database Configuration (server/config/db.js)
----------------------------------------------
Purpose: Establishes and manages database connection
Key Features:
- Uses Sequelize ORM for PostgreSQL
- Configures connection pool
- Handles database authentication
- Syncs database models

Code Explanation:
```javascript
const sequelize = new Sequelize({
  host: process.env.DB_HOST,
  dialect: 'postgres'
  // ... other configurations
});
```
- Creates database connection with environment variables
- Manages connection pooling for performance
- Provides error handling for connection issues

1.2 User Model (server/models/User.js)
------------------------------------
Purpose: Defines user data structure and authentication methods
Key Features:
- UUID-based user identification
- Password hashing with bcrypt
- Role-based access control
- Public key storage for encryption

Important Methods:
- matchPassword(): Verifies user password
- beforeCreate hook: Hashes password before saving
- User schema includes:
  * username (unique)
  * email (unique)
  * password (hashed)
  * role (voter/admin)
  * publicKey (for vote encryption)
  * hasVoted (voting status)

1.3 Vote Model (server/models/Vote.js)
------------------------------------
Purpose: Stores encrypted votes
Key Features:
- UUID-based vote identification
- Encrypted vote storage
- Association with User model
- Election tracking

Schema:
```javascript
{
  id: UUID,
  encryptedVote: TEXT,
  electionId: STRING,
  voterId: UUID (foreign key)
}
```

1.4 Authentication Controller (server/controllers/authController.js)
---------------------------------------------------------------
Purpose: Handles user authentication and registration
Key Features:
- User registration with key generation
- Login with JWT token generation
- Role verification
- Admin code validation

Important Functions:
1. registerUser():
   - Validates user input
   - Generates encryption keys
   - Creates user record
   - Returns JWT token

2. loginUser():
   - Verifies credentials
   - Manages encryption keys
   - Issues JWT token
   - Handles role-based redirection

1.5 Vote Controller (server/controllers/voteController.js)
------------------------------------------------------
Purpose: Manages voting operations
Key Features:
- Vote submission
- Vote verification
- Real-time updates
- Double-voting prevention

Key Functions:
1. submitVote():
   - Validates voter eligibility
   - Stores encrypted vote
   - Updates voting status
   - Broadcasts update

2. verifyVote():
   - Decrypts vote data
   - Validates authenticity
   - Returns verification result

6. DATABASE SCHEMA
=================
1. Users Table:
   ```sql
   CREATE TABLE Users (
     id UUID PRIMARY KEY,
     username VARCHAR UNIQUE,
     email VARCHAR UNIQUE,
     password VARCHAR,
     role VARCHAR,
     hasVoted BOOLEAN,
     publicKey TEXT
   );
   ```

2. Votes Table:
   ```sql
   CREATE TABLE Votes (
     id UUID PRIMARY KEY,
     encryptedVote TEXT,
     electionId VARCHAR,
     voterId UUID REFERENCES Users(id)
   );
   ```
