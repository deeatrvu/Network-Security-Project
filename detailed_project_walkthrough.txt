Detailed Project Walkthrough: How Each Component Works
================================================

1. User Journey and Component Interaction
---------------------------------------

A. Registration Process
----------------------
When a new user registers:
1. The Register component collects user information:
   ```javascript
   // Register.js handles:
   - Username/email validation
   - Password strength checking
   - Role selection (voter/admin)
   - Encryption key generation
   ```

2. Security measures during registration:
   - Passwords are hashed using bcrypt before storage
   - A unique key pair is generated for vote encryption
   - Public key is stored in database
   - Private key is stored in user's browser storage securely

B. Login Process
---------------
When a user logs in:
1. The Login component:
   - Validates credentials
   - Retrieves stored encryption keys
   - Sets up user session

2. Authentication flow:
   ```javascript
   // Login process:
   1. User enters credentials
   2. Password is hashed and compared
   3. JWT token is generated with user role
   4. Encryption keys are loaded
   5. User is redirected based on role
   ```

2. Voting Process
----------------

A. Voter's Perspective
---------------------
When a voter casts a vote:
1. VotingPage component:
   - Displays available voting options
   - Handles vote selection
   - Encrypts vote before submission
   
2. Vote submission process:
   ```javascript
   // Voting flow:
   1. User selects their vote
   2. Vote is encrypted using public key
   3. Encrypted vote is sent via WebSocket
   4. Real-time confirmation is displayed
   5. Page updates to prevent double voting
   ```

B. Vote Processing
-----------------
Server-side vote handling:
1. Vote verification:
   - Checks user hasn't voted before
   - Validates vote format
   - Verifies encryption

2. Storage process:
   ```javascript
   // Vote storage:
   1. Encrypted vote is validated
   2. Database record is created
   3. Vote count is updated
   4. WebSocket broadcasts update
   5. Audit log is updated
   ```
