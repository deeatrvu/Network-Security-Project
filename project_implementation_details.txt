2. Backend Implementation
-------------------------

A. Authentication System
Location: /server/controllers/auth.js
Technologies Used:
- bcryptjs for password hashing
- jsonwebtoken for session management
- Express.js for routing
Why:
- Secures user credentials
- Manages user sessions
- Controls access to protected routes
Example Implementation:
```javascript
// In auth.js
const login = async (req, res) => {
  // Hash password comparison
  const isValid = await bcrypt.compare(password, user.password);
  if (isValid) {
    // Generate JWT token with role
    const token = jwt.sign({ id: user.id, role: user.role });
    res.json({ token });
  }
}
```

B. Vote Processing System
Location: /server/controllers/vote.js
Technologies Used:
- crypto-js for vote decryption
- Sequelize for database operations
- WebSocket for real-time updates
Why:
- Processes encrypted votes
- Prevents double voting
- Updates vote counts in real-time
Example Implementation:
```javascript
// In vote.js
const processVote = async (encryptedVote, userId) => {
  // Check for existing votes
  const hasVoted = await Vote.findOne({ where: { userId }});
  if (!hasVoted) {
    // Store encrypted vote
    await Vote.create({ 
      userId,
      encryptedVote,
      timestamp: new Date()
    });
    // Broadcast update via WebSocket
  }
}
```
